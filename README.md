# ModernBERT & NeoBERT: Эксперименты с длинным контекстом для задачи Extractive QA

Данный репозиторий содержит программный код, скрипты и аналитические материалы, разработанные в рамках магистерской диссертации на тему: **«Локализация релевантных текстовых фрагментов в документно-ориентированном question answering с использованием ModernBERT»**.

Проект посвящен исследованию и оценке эффективности применения современных энкодерных архитектур (ModernBERT, NeoBERT) для решения задачи поиска точного ответа (Extractive Question Answering) в длинных текстах.

## 🎯 Цель проекта

Разработка и исследование метода локализации релевантных фрагментов текста (span) в длинных документах по заданному вопросу с использованием моделей ModernBERT и NeoBERT.

В рамках проекта проводится комплексный анализ влияния архитектурных и параметрических факторов на качество выделения ответа:

* **Длины входного контекста** (от 512 до 8192 токенов).


* **Стратегии разбиения документов** (chunking) и гранулярности извлечения.


* **Позиции ответа в документе** (оценка эффекта «Lost in the middle» / позиционного смещения).



## 💡 Практическая значимость

Несмотря на популярность RAG-систем на базе больших генеративных языковых моделей (LLM), они остаются подвержены «галлюцинациям». Использование encoder-only моделей (ModernBERT, NeoBERT) позволяет:

* Снизить вычислительные затраты и повысить скорость работы системы.


* Гарантировать фактологическую точность ответа за счет прямого извлечения (экстракции) текста из документа.


* Обеспечить более прозрачную интерпретацию результатов.

Данное исследование показывает границы применения encoder-only  моделей для построения вопросно-ответных систем, а также производится систематическое сравние с decoder моделями. Обученные для задачи QA ModenBERT и NeoBERT готовы к использованию и практическому применению в реальных системах, так как они демонтсрируют высокую точность на реальных датасетах.

## 📁 Структура репозитория

Проект разделен на логические модули, каждый из которых представляет отдельный этап исследования. Подробные инструкции по запуску находятся внутри каждой директории.

* **`ModernBERT/`** — скрипты для тонкой настройки (fine-tuning) и оценки модели ModernBERT на очищенном датасете Natural Questions.


* **`NeoBERT/`** — адаптация пайплайна обучения и инференса для энкодера нового поколения NeoBERT с использованием кастомной QA-головы.


* **`Position_bias_BERT_models/`** — исследовательская среда для оценки эффекта позиционного смещения (Position Bias). Позволяет искусственно манипулировать положением правильного ответа внутри контекста (начало, середина, конец) и оценивать деградацию качества с расчетом статистической значимости.


* **`sliding_window_qa/`** — реализация двухэтапного пайплайна (Two-Stage Pipeline). Включает модуль интеллектуального чанкинга по границам предложений со скользящим окном (Sliding Window), реранкер (Cross-Encoder) и финальный экстрактор спанов.


* **`RAG_NQ/`** — экспериментальная среда для сравнения энкодеров с компактными генеративными декодерами (например, SmolLM2, Phi-4-mini) в режиме *Oracle*. Включает расчет лексических (EM, F1) и семантических метрик (BERTScore, BLEURT).


* **`NQ_HTML_CLEANER/`** — скрипты предварительной обработки датасета Natural Questions. Удаление HTML-разметки, фильтрация примеров без ответов и пересчет глобальных координат токенов.


* **`NQ_analytics/`** — инструменты для исследовательского анализа данных (EDA), визуализации распределения длин документов и ответов.

## 📊 Основные результаты исследования

В ходе экспериментов были получены следующие выводы, подтверждающие эффективность предложенных методов:

1. **Высокая точность энкодеров:** Модели NeoBERT и ModernBERT продемонстрировали высокую эффективность в задаче экстрактивного поиска (EM ~79-80%, F1 ~85-86%), значительно превзойдя компактные генеративные декодеры в точности строгого извлечения фактов.


2. **Позиционное смещение (Position Bias):** Базовые архитектуры подвержены эффекту «первичности» — качество извлечения монотонно затухает по мере удаления ответа от начала документа. Применение аугментации данных сдвигами контекста на этапе обучения позволяет частично компенсировать этот эффект.


3. **Оптимальная стратегия извлечения:** Способность модели обрабатывать до 8192 токенов не гарантирует сохранения пиковой точности. Наилучшие результаты достигаются при использовании двухэтапного подхода: длинные окна контекста используются на этапе ранжирования (Retrieval), а короткие окна (512 токенов) — для точной финальной локализации ответа (Span Extraction).

## 🛠 Требования и Установка

Для корректной работы проекта рекомендуется использовать **Python 3.10 – 3.12** и графический ускоритель NVIDIA (рекомендуется от 8 ГБ видеопамяти) с поддержкой CUDA.

### 1. Клонирование репозитория
Склонируйте проект и перейдите в директорию:
```bash
git clone [https://github.com//SolodnikovaSophie/ModernBERT_NeoBERT_experiments_with_long_context.git](https://github.com//SolodnikovaSophie/ModernBERT_NeoBERT_experiments_with_long_context.git)
cd ModernBERT_NeoBERT_experiments_with_long_context

```

### 2. Создание виртуального окружения

Изолированное окружение поможет избежать конфликтов библиотек.

```bash
python -m venv venv

# Активация для Windows:
venv\Scripts\activate

# Активация для Linux / macOS:
source venv/bin/activate

```

### 3. Установка PyTorch (с поддержкой CUDA)

**Важно:** Проект активно использует GPU-вычисления. Базовая команда `pip install torch` может установить версию для процессора (CPU). Сначала установите PyTorch с нужной версией CUDA (в проекте использовалась CUDA 12.4).

Для Windows / Linux:

```bash
pip install torch torchvision torchaudio --index-url [https://download.pytorch.org/whl/cu124](https://download.pytorch.org/whl/cu124)

```

### 4. Установка зависимостей проекта

После установки PyTorch установите остальные библиотеки из файла `requirements.txt`:

```bash
pip install -r requirements.txt

```
