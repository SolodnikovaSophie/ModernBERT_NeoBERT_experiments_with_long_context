# Оценка позиционной устойчивости (Position Bias) в энкодерных моделях

Данный проект посвящен исследованию эффекта «позиционного смещения» (Position Bias) у современных энкодерных моделей (в частности, ModernBERT) в задаче Extractive Question Answering. 

В отличие от классического инференса, этот исследовательский пайплайн позволяет искусственно манипулировать положением правильного ответа внутри подаваемого контекста и замерять деградацию качества модели по мере смещения ответа к концу документа.

---

## 🔬 Суть эксперимента

Модели часто привыкают находить ответы в начале текстов, из-за чего их качество резко падает при обработке длинных документов (Long-Context QA). Эксперимент построен следующим образом:

1. **Манипуляция контекстом:** Для каждого вопроса из валидационной выборки окно контекста нарезается не случайным образом, а так, чтобы правильный ответ принудительно оказался на заданной относительной позиции (например, `0.0` — начало, `0.5` — середина, `1.0` — конец).
2. **Масштабирование длины:** Эксперимент параллельно прогоняется для разных размеров окна (от 512 до 4096 токенов), чтобы выявить зависимость между длиной последовательности и силой позиционного смещения.
3. **Статистическая оценка:** Рассчитываются базовые метрики (EM, F1, Recall, RougeL), доверительные интервалы (Confidence Intervals), а также проводятся тесты на статистическую значимость падения метрик.

---

## 📁 Структура проекта и описание файлов

Кодовая база разделена на логические модули для удобства проведения и анализа экспериментов:

### Основной пайплайн
* `run_position_bias.py` — главный скрипт инференса. Запускает модель, прогоняет через нее датасет с принудительным смещением окна и сохраняет сырые логиты/предсказания.
* `config.py` — парсинг гиперпараметров и настроек эксперимента (размеры окон, исследуемые позиции, пути к моделям).
* `data_utils.py` — загрузка датасета и ключевая логика паддинга/слайсинга контекста для точного позиционирования ответа в заданном бине (0.0, 0.25, 0.50, 0.75, 1.0).

### Оценка и вычисления
* `metrics.py` — реализация функций оценки качества SQuAD (Exact Match, F1-score) и дополнительных метрик (Recall, RougeL).
* `memory.py` — утилиты для мониторинга и управления памятью (CPU/VRAM), предотвращающие ошибки Out-Of-Memory при инференсе с длинными окнами.

### Статистика и визуализация
* `stat_test_bias.py` — расчет доверительных интервалов (CI) и проверка статистической значимости различий метрик между началом и концом документа.
* `check_length_significance.py` — анализ того, насколько статистически значимо падает качество модели при переходе от коротких окон (512) к длинным (4096).
* `plot_results.py` — генерация графиков зависимости качества (F1/EM) от позиции ответа.
* `plot_length_metrics.py` — генерация графиков деградации качества при увеличении длины контекста.

## 💻 Запуск и использование

### 1. Запуск основного эксперимента (Инференс)
Для запуска прогона модели с заданными параметрами смещения контекста используйте конфигурационный файл (убедитесь, что пути к данным и модели настроены корректно):

```bash
python run_position_bias.py --config configs/config.yaml

```

### 2. Статистический анализ

После завершения инференса подтвердите, что наблюдаемое падение качества не является случайным:

* **Тест на значимость позиционного смещения** (сравнивает метрики в начале и в конце документа):
```bash
python stat_test_bias.py

```


* **Тест на влияние длины контекста** (оценивает ухудшение работы при переходе к длинным окнам):
```bash
python check_length_significance.py

```



### 3. Визуализация результатов

Для генерации графиков выполните следующие команды:

* **Графики позиционного смещения (Position Bias):**
```bash
python plot_results.py

```


* **Графики деградации от длины контекста:**
```bash
python plot_length_metrics.py

```
